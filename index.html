ShieldVultus Web

URL scanning, file-hash lookup, and shortened-link resolution - powered by VirusTotal.

What this can and can't do: this web version scans and reports on threats. It cannot quarantine or remove files from your computer - that needs real filesystem access, which only the desktop version of ShieldVultus has. Think of this as the "check before you click" companion, not a replacement for it.

Your VirusTotal API key

Free at virustotal.com (no card needed). Stored only in your own browser - never sent anywhere except directly to VirusTotal through this site's proxy.

Scan a URL

Submits the URL to VirusTotal and checks it against dozens of security vendors.

Look up a file hash

Paste a SHA256, SHA1, or MD5 hash to see if that file is known to be malicious - no need to upload the file itself.

Resolve a shortened link

Follows redirects so you can see where a shortened or disguised link actually leads, before you click it. Doesn't need an API key.

Scan a QR code

Upload a photo of a QR code (or take one, on mobile). Decoded entirely in your browser - the image never leaves your device. If it decodes to a link, you can send it straight to the URL scanner above.

Check if a password was breached

Your password never leaves your browser. It's hashed locally and only the first 5 characters of that hash are sent to check against HaveIBeenPwned's Pwned Passwords database - this is a k-anonymity design, not a guess: it's mathematically impossible for the server to reconstruct your password from what it receives.

Check if an email was breached

Searches breach.vip's leaked-credential database for this email address. This is public breach data already circulating - only check accounts you own or are authorized to check.

Batch check

Paste multiple URLs and/or file hashes, one per line. Runs one at a time to stay within VirusTotal's free-tier rate limit (about 15 seconds apart) - a batch of 10 takes a couple of minutes.

Scan history clear

Your last 50 checks on this device. Not shared with anyone.

Report a scam

Seen a phishing link, fake giveaway, impersonation account, or invite-reward scam? Report it here so others checking the same link or handle get warned.

Recent community reports

Public and unmoderated - use judgement, this is crowd-sourced, not verified.
